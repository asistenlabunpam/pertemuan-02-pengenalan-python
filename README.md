# Pertemuan 2: Pengenalan Pemrograman Python

## Deskripsi
Proyek ini berisi dasar-dasar bahasa pemrograman Python 3 yang dibahas pada Pertemuan 2. Topik meliputi pengenalan variabel, tipe data numerik, operasi string, operasi list, format string, percabangan kondisi, operator logika (`and`, `or`, `not`, `in`, `is`), serta perulangan dasar (`for`).

## Program yang Tersedia
1. `01_halo_nama.py`: Pengenalan sintaks dasar pengeluaran string dan variabel nama.
2. `02_hello_world.py`: Mencetak kalimat Hello World / Selamat datang di Python 3.
3. `03_variabel_dan_tipe_data.py`: Penggunaan variabel tipe data float, int, dan operasi aritmatika dasar.
4. `04_operasi_list_dan_string.py`: Operasi manipulasi list (`append`), penggabungan string, perkalian string, dan pemformatan gaya C (`%s`).
5. `05_kondisi_dan_operator.py`: Penggunaan operator perbandingan (`==` vs `is`), operator logika (`and`, `or`, `not`), pencarian dalam himpunan (`in`), dan perulangan `for`.

## Cara Menjalankan
Jalankan skrip yang diinginkan dengan Python:
```bash
python 01_halo_nama.py
python 02_hello_world.py
python 03_variabel_dan_tipe_data.py
python 04_operasi_list_dan_string.py
python 05_kondisi_dan_operator.py
```
